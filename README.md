# Dosa & Podi — Static Demo Site

Lightweight static demo website for the Dosa & Podi listing. Contains a modern, responsive UI with subtle animations and links to reserve/order pages.

Files
- index.html — main page
- css/styles.css — styling
- js/app.js — minimal interactivity

Preview locally
1. Open `index.html` directly in a browser.
2. Or serve the folder with a simple HTTP server:

```bash
cd "$HOME/Desktop/dosa-site"
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```
